Feature: What Can This App Do?

  • Edit and rearrange various elements (text, shapes) on a canvas visually and interactively.
  • Customize properties such as position, size, rotation, border, background, and z-index.
  • Add, edit, and style text boxes including font size and color customization.
  • Export your design as JSON for later editing or as HTML for use in your projects.
  • Live preview of all changes as you edit each element.
  • User-friendly drag and drop interface for easy element positioning.
  • Pan and zoom the canvas: zoom in/out and move left/right drag.
